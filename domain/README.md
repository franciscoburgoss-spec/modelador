# Dominio constructivo

`DOMAIN_RULES.md` conserva las reglas transversales verificadas del proyecto heredado.
`ROADMAP-R1-R8.md` conserva la secuencia de implementación: R1–R6 y R7-A/B están cerrados.
`specs/domain/SPEC-R7-checks.md` está aprobada y activa en el corte C; R8 permanece pendiente.

Una regla nueva necesita fuente, alcance, origen, severidad y evidencia. No se modifica una decisión
histórica para corregirla: se registra una decisión nueva en `governance/DECISIONS.md`.
