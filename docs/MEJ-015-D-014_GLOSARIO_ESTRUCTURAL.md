# MEJ-015-D-014 — Glosario estructural único y contextual

## Objetivo

Evitar que términos como `Apoyo lateral`, `Candidato`, `Una dirección` o `Diafragma previsto` se interpreten como verificaciones, soluciones constructivas o inferencias automáticas.

## Implementación REV7

Se incorpora `structural-concept-glossary-v1.0` como fuente semántica única de UI para:

- distribución resistente de cubierta;
- comportamiento de diafragma;
- funciones de borde;
- estados de propuestas;
- estados de caminos candidatos.

Cada concepto declara cuatro capas:

1. significado;
2. qué declara el usuario;
3. efecto en los motores;
4. qué **no** significa.

La pestaña `Conceptos` de SPEC-015-D muestra el glosario completo y `Intención estructural → Techumbre` muestra ayuda contextual debajo de las elecciones vigentes.
